# KnowForge RAG Platform V1.0.11

发布日期：2026-07-21

V1.0.11 是 V1.0.10 的工程清理补丁，不改变业务功能、接口、数据库结构、检索参数或场景数据。

## 本次清理

- 删除旧版 `docker-compose.milvus.yml`，只保留标准 `docker-compose.yml` 部署入口。
- 删除未进入课程导航的内部代码流程动画，正式讲义与章节动画不受影响。
- 精简本地环境诊断逻辑，去除旧 Compose 端口探测分支。
- 增加废弃路径守卫，防止历史文件重新进入发布包。

## 保留边界

- `codealong/` 是逐章可运行的教学快照，不属于重复代码。
- `site/` 是可离线打开的网页版讲义，不属于重复文档。
- `scripts/` 中独立命令均保留，因为它们承担部署、验收、评测、治理或数据维护职责。

## 外部验收状态

模型权重不进入源码压缩包。当前 DashScope 账户状态仍可能阻断在线生成验收，但不影响代码、Docker、检索、意图模型与离线发布门禁。
